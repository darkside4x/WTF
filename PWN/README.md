# PWN (Binary Exploitation) Challenges

This directory contains writeups for binary exploitation challenges.

## Common Topics

- Buffer overflows
- Return-oriented programming (ROP)
- Stack canaries bypass
- ASLR/PIE bypass
- Format string vulnerabilities
- Heap exploitation
- Use-after-free vulnerabilities
- Race conditions

## Tools Often Used

- GDB with pwndbg/peda
- pwntools (Python library)
- ROPgadget/ropper
- Checksec
- Radare2/Ghidra
- Valgrind
