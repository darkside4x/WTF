# WTF - What The Flag

Repository for CTF writeups by IEEE CS VIT Vellore

## About

This repository contains writeups for various Capture The Flag (CTF) competitions and challenges. It serves as a learning resource and documentation of problem-solving approaches for cybersecurity challenges.

## Repository Structure

```
├── Web/                 # Web application security challenges
├── Crypto/              # Cryptography and cryptanalysis challenges  
├── Reverse/             # Reverse engineering challenges
├── PWN/                 # Binary exploitation challenges
├── Forensics/           # Digital forensics challenges
├── OSINT/               # Open source intelligence challenges
├── Misc/                # Miscellaneous challenges
├── Steganography/       # Steganography and data hiding challenges
├── WRITEUP_TEMPLATE.md  # Template for creating new writeups
└── README.md           # This file
```

## Contributing

1. **Fork** the repository
2. **Create** a new branch for your writeup: `git checkout -b writeup/challenge-name`
3. **Use** the provided template (`WRITEUP_TEMPLATE.md`) for consistency
4. **Place** your writeup in the appropriate category directory
5. **Name** your file descriptively: `challenge-name.md`
6. **Include** any relevant files, scripts, or tools used
7. **Submit** a pull request with a clear description

## Writeup Guidelines

- Use the provided template for consistency
- Include clear step-by-step explanations
- Provide code snippets and tool commands used
- Explain your thought process and methodology
- Include the final flag (if appropriate)
- List tools and resources used
- Add screenshots when helpful

## Categories

Each category directory contains its own README with common topics and tools for that challenge type.
